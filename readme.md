# 🎁 MERN Wishlist App

ეს არის **MERN (MongoDB, Express, React, Node.js) აპლიკაცია**, რომელიც მომხმარებლებს საშუალებას აძლევს შექმნან, რედაქტირებად და წაშალონ სურვილების სია.  
აპლიკაციას აქვს **მომხმარებლის რეგისტრაცია და ავტორიზაცია JWT-ით**, ასევე Dark Mode UI.

---

## 🚀 ფუნქციონალი

### 👨‍🎓 მომხმარებლის მხარე
- რეგისტრაცია და ლოგინი
- სურვილების დამატება
- სურვილების რედაქტირება
- სურვილების წაშლა
- სურვილების დასრულების მონიშვნა
- სურვილების გადანაწილება **Pending** და **Completed** სექციებად

### 🔑 ადმინისტრატორის მხარე
- ყველა ფუნქცია ხელმისაწვდომია მხოლოდ ავტორიზირებულ მომხმარებლებს
- დაცულია **JWT token-ით**

---

## 🛠️ გამოყენებული ტექნოლოგიები
- **Frontend:** React + TailwindCSS  
- **Backend:** Node.js + Express  
- **Database:** MongoDB  
- **Authentication:** JWT  
- **Deployment:** Render.com მზად
